# SIGMA GROUP — B2B Marketplace

واجهة عربية RTL تجريبية متكاملة لمنصة مشتريات وتوريدات الشركات.

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح الرابط الذي يظهر في الطرفية.

## البناء والنشر
```bash
npm run build
```
تم إعداد GitHub Actions للنشر إلى GitHub Pages. غيّر `base` في `vite.config.js` لاسم مستودعك إذا لم يكن `sigma-group`.

## بيانات الدخول التجريبية
- العميل: اختر "دخول كعميل تجريبي".
- الإدارة: اختر "دخول كإدارة تجريبية".

## مهم قبل التشغيل التجاري
هذه نسخة Front-end تجريبية تستخدم localStorage في المتصفح. لا تستخدم بيانات أو أسعار أو فواتير حقيقية. يلزم ربط Backend وقاعدة بيانات وصلاحيات موثوقة، والتحقق القانوني/الترخيصي، قبل اعتمادها تجارياً. لا تعتبر بيانات المتصفح نظاماً محاسبياً أو مخزوناً موثوقاً.
